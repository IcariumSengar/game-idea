# game-idea

Initial repo for game idea — a Godot 4.4 project.

## Prerequisites

- [Godot 4.4](https://godotengine.org/download) (stable)

## Getting started

1. Clone this repository.
2. Open Godot 4.4 and choose **Import** or **Open**.
3. Select `project.godot` in the repo root.
4. Press **F5** (or click Run) to launch the project.

You should see the Main Menu.

## Project layout

```text
project.godot            Godot project config
scenes/ui/main_menu.tscn Entry scene
VERSION             Current released version
CHANGELOG.md        Release history
VERSIONING.md       How to cut and roll back versions
```

## Versioning

Fixed versions (`v1`, `v2`, …) are tagged milestones you can roll back to at any time. See [VERSIONING.md](VERSIONING.md) for the full release and rollback workflow.
